# 资料收集与操作引导

## 开始时需要明确的内容

默认修改现有 VPS 远程订阅，通过订阅级“扩展脚本”添加链路，保留刷新入口。先让用户指出具体订阅卡片。独立本地 YAML 仅在用户明确选择时交付。

默认同时交付完整“订阅扩展脚本.txt”和“订阅扩展覆写.txt”。前者负责前置机场和双出口，后者采用技能内通用分流基线，按目标电脑适配国内直连规则与 DNS。朋友已有的订阅级和全局扩展仍需收集，用于判断差异及组合结果。

先确认是在当前可访问电脑上操作，还是为另一台电脑生成文件。读到的信息按实际来源标明。已有订阅通常能提供协议、地址、端口和认证信息，用户只需确认哪个节点对应纯 VPS、哪个对应住宅出口。

| 项目 | 获取办法 | 未确定时询问 |
| --- | --- | --- |
| 客户端与版本 | 应用版本、Mihomo `/version` | 系统和客户端名称/版本 |
| 目标订阅 | 客户端订阅列表及注册配置 | 修改哪张订阅，或新建一张 |
| 两个入口的角色 | 节点参数加用户确认，必要时出口探测 | 纯 VPS 与 VPS → 住宅的节点名称 |
| 机场来源 | 当前可用独立机场订阅 | 机场订阅链接，或已有订阅名称 |
| 分流 | 原 rules、rule-providers、DNS、已有脚本 | 沿用哪份分流，或用户需要的国内直连范围 |
| 导入方式 | 用户已有偏好与本机文件权限 | 用户复制保存，还是授权代操作 |

如果只有一个入口，先问它的作用和第二个入口是否存在。3X-UI 通过不同入口或路由区分出口时，需要拿到对应的两个真实分享链接。仅凭一个客户端节点无法凭空创建服务器侧的另一条出口。

两段式的含义应向用户讲清楚。第一组决定电脑怎样连接 VPS，第二组决定网站看到 VPS 还是住宅出口。机场可以是同一家或另一家，住宅供应商参数由已完成的服务器侧路由处理。

## 给无法本机读取的用户

可请求如下资料，已知项提前填入。遵守用户的问答节奏，仅追问剩余缺口。

```text
目标设备和系统
Clash 客户端版本，以及能看到的内核版本
新建订阅，或修改的订阅名称
机场订阅链接，或可导出的机场配置
纯 VPS 节点分享链接，或含该节点的配置
VPS → 住宅节点分享链接，或含该节点的配置
要沿用的分流配置，或国内直连需求
希望自己复制导入，还是允许在可访问设备上代操作
```

收到含令牌的配置后，避免把原文回显。用户专属配置产物可以包含运行必需的认证资料，通用 skill、示例和报告使用合成数据。

## 朋友电脑的逐项取资料步骤

以下中文菜单在 Clash Verge Rev v2.5.9 实机只读核对过。遇到其他客户端或菜单不同，先请用户发“设置”和“订阅”页面截图，再按实际界面指引。收集阶段只打开、复制、取消。

### 1. 版本和订阅截图

1. 打开 Clash Verge，点击左侧“设置”。
2. 向下滚动，找到“Clash 设置”中的“Clash 内核”，截图这一行。
3. 找到“Verge 高级设置”底部的“Verge 版本”，截图这一行。
4. 告诉我们 Windows 10 / Windows 11，或实际系统名称。
5. 点击左侧“订阅”，截图订阅卡片列表，并指出机场卡片和 VPS 卡片。名字相同的卡片要圈出具体一张。

### 2. 机场链接和当前机场配置

1. 在“订阅”页，对当前独立使用正常的机场卡片点击鼠标右键。
2. 点击“编辑信息”，在“订阅链接”输入框内单击，再按 Ctrl+A、Ctrl+C，粘贴发送并标注“机场订阅链接”。
3. 同一窗口查看“用户代理”。填写过则复制填写值，空白则回复“用户代理空白”。灰色提示文字可截图，用于核对默认客户端标识。
4. 点击“取消”。
5. 再次右键同一张机场卡片，点击“编辑文件”。单击代码正文后 Ctrl+A、Ctrl+C。
6. 打开记事本，Ctrl+V，另存为“机场原配置.txt”，发送文件。回 Clash 点击“取消”。该配置用于比对实际节点、协议及专用 DNS。

### 3. VPS 两个入口

1. 对包含纯 VPS 和住宅出口的订阅卡片右键，点击“编辑文件”。
2. 单击代码正文，Ctrl+A、Ctrl+C，粘贴到记事本并保存“VPS原配置.txt”，发送文件，回 Clash 点击“取消”。
3. 若两个入口分在两张订阅卡片，分别复制并标注用途。
4. 用户写明“纯 VPS 对应节点名 ____；VPS → 住宅对应节点名 ____”。不确定时先发送配置，由助手列出节点名再确认角色。
5. 默认修改远程 VPS 订阅，再按机场取链接的相同步骤，从该卡片“编辑信息 → 订阅链接”复制 VPS 订阅链接，用于核对来源和更新可达性。

连接参数必须从真实配置或可用订阅获得。节点名截图可辅助对应角色。

### 4. 原有分流与扩展

当用户要保留原分流或修改原订阅时，对该 VPS 卡片右键，分别打开“扩展覆写配置”和“扩展脚本”，复制全部正文，分别保存为“VPS扩展覆写.txt”和“VPS扩展脚本.txt”，每次复制后点击取消。默认模板也可以原样发送，由助手判断。

订阅页面底部另有“全局扩展覆写配置”和“全局扩展脚本”。打开后用相同方式复制全文。它们可能影响新建订阅，应在正式验证前核对。用过右键菜单的“编辑规则”“编辑节点”“编辑代理组”时，请用户说明用过哪些，继续采集对应内容或目标订阅的运行时配置，核对最终合成结果。

同时让用户列出需要国内直连的应用及网站，并确认要修改的现有 VPS 订阅名称。用户明确选择新建时再说明对应交付方式。

### 5. 收到成品后的具体操作

默认交付完整“订阅扩展脚本.txt”。用户先复制备份原脚本，再到“订阅 → 右键指定 VPS 卡片 → 扩展脚本”，单击正文后 Ctrl+A，将交付的完整脚本粘贴进去并保存。随后右键该卡片选择“使用”，进入左侧“代理”，选择前置及出口。生成前应已合并原脚本的必要功能。

配套的“订阅扩展覆写.txt”放在同一张 VPS 卡片的“右键 → 扩展覆写配置”。先备份原内容，再单击正文，Ctrl+A、Ctrl+V 完整替换并保存。两份文本必须成套生成并验证，组名、规则引用及机场 DNS 保持一致。应用顺序按实际客户端的处理流程给出，解释保存可能触发重载与短暂重连，优先在其他可用订阅处于使用状态时编辑目标卡片，两份保存后再使用目标订阅。避免单份保存后就声称完成。

订阅卡片上的刷新按钮更新 VPS 远程来源，扩展脚本在配置处理时继续应用。前置机场 provider 有独立更新周期，其更新结果需要另行检查。当前通用模板会检查两个 VPS 节点的名称、服务器与端口，改变这些字段需要重新核对脚本映射。VPS 订阅链接打不开时，要单独验证通过可用机场更新的方式。

用户明确选择本地模式时，交付“链式代理.yaml”。打开“订阅 → 新建”，类型选择“本地”，填写名称，点击“选择文件”选择 YAML 并保存。右键新卡片选择“使用”，再进入“代理”选择前置及出口。完整 YAML 的文件选择入口已核对，正式保存和联网效果需要目标电脑验收。

导入后让用户发送两个选择组截图，并通过实际连接记录与公网出口验收。查看配置和菜单不等于已验证朋友电脑联网。

资料文件及订阅链接含连接凭据，应通过双方认可的私密渠道发送。公共教程和可复用技能包使用合成数据。

## 修改原订阅的处理流程

1. 定位目标订阅对应的 YAML、扩展配置和订阅级脚本。
2. 备份并理解原脚本及覆写用途，生成完整配套候选，列出分流迁移差异。
3. 指导用户找到同一目标订阅右键菜单的“扩展覆写配置”和“扩展脚本”。界面文字以实际版本为准。
4. 分别全选替换对应的完整文本，按已验证的应用步骤保存两份，再使用目标订阅。
5. 到代理页选择前置节点及出口。
6. 读取正式加载状态与公网出口，确认导入效果。

若已有脚本用于解锁、节点重命名或其他转换，保留它的处理顺序与功能，使用实际合并输出验证。通用模板适用于已解析的 Mihomo 配置对象。

## 新建订阅

需要新建且有 VPS 远程订阅链接时，优先导入远程订阅，再添加完整订阅级脚本。用户明确选择本地文件时，交付包含两个真实入口、机场 provider、两个选择组、用户分流及 DNS 的完整 YAML，按上方本地模式步骤导入。

机场 provider 按配置定期更新。静态写入的 VPS 入口参数改变后，需要重新生成文件。若用户要求 VPS 入口也跟随订阅自动更新，可保留远程 VPS 订阅，再给该订阅应用完整脚本，并明确两者各自的位置。

新建配置的规则应引用实际出口组。可使用现有 AI服务 / PROXY 名称，或建立出口选择组。若新配置采用简单 MATCH 默认出口，先获得用户对直连范围的选择，形成可解释的分流。

## 日常使用说明

用用户实际看到的名称替换下面的通用名称。

| 前置机场 | 出口选择 | 访问路径 |
| --- | --- | --- |
| 某机场节点 | 纯 VPS | 电脑 → 机场 → VPS → 网站 |
| 某机场节点 | 住宅出口 | 电脑 → 机场 → VPS → 住宅 → 网站 |
| 不经过机场（直连） | 纯 VPS | 电脑 → VPS → 网站 |
| 不经过机场（直连） | 住宅出口 | 电脑 → VPS → 住宅 → 网站 |

“不经过机场”与整台电脑的 DIRECT 模式作用不同，需要向用户明确它只改变连接 VPS 的前置方式。若用户另有“机场单独出口”需求，再添加有明确用途的选项。

恢复方法应具体到原订阅和原脚本备份。导入失败时先取错误文本及实际加载状态，再选择恢复备份或修正候选。内核开关超时后先检查残留进程和服务状态。
